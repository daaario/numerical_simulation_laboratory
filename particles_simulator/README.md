# Simulator - for Numerical Simulation Lab (Unimi)
A combined simulator that can run 
- Ising chain (1D) MC simulation: can run using a Metropolis or a Gibbs algorithm
- Lennard-Jones system: can run in MD mode (Verlet algorithm) or in MC mode (Metropolis algorithm)

The simulations parameters are set in 'input/sys_settings.dat', 'input/ising_settings.dat' and 'input/lj_settings.dat'.
Run the simulation executing './source/run'.
The simulation results are CSV files contained in 'output/'.
