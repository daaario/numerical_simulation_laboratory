# Numerical Simulation Laboratory - Unimi

This repository contains Jupyter notebooks detailing the solutions of exercises for the 'Numerical Simulation Laboratory' course at Università dgli Studi di Milano.

Other directories contain self-contained (C++) programs such as:
- *'particles_simulator'*: a program to simulate, using a variety of Monte Carlo and deterministic algorithms, either a 1D Ising chain or a 3D Lennard-Jones system enclosed in a periodic box.
- *'tsp_genetic_algorithm'*: a program to solve, using a genetic algorithm, the Traveling Salesman Problem over a series of given or randomly generated cities.
- *'rannyu_rng'*: a (pseudo-)random numbers generator, called directly in some notebooks or re-used as an additional class in the two programs above.

The *'sim_results'* directory contains output data generated from these programs: these get analyzed an plotted in some notebooks.
